# Documentation Workspace

This directory will hold presentation-quality engineering material derived from validated repository data.

Planned subdirectories:

- `diagrams/` — geometry, network, water, and electrical diagrams;
- `renders/` — concept renders clearly labelled as illustrative;
- `reports/` — exported formal studies and government-facing reports.

Rule: illustrations must not be presented as construction drawings unless they are issued and reviewed as such.
