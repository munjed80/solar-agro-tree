# Water Simulation Workspace

This directory is reserved for pumping, irrigation-demand, reservoir, and water-balance models.

Future site-specific models should include:

- static and dynamic water levels;
- total dynamic head;
- pump curves and efficiency;
- pipe friction losses;
- reservoir elevation;
- irrigation schedule;
- crop evapotranspiration;
- rainfall contribution;
- water quality and treatment energy;
- sustainable abstraction constraints.

Reference concept calculations are documented in `WATER_MODEL.md`.
