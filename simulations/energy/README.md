# Energy Simulation Workspace

This directory is reserved for site-specific photovoltaic yield models and exported results.

Final modelling should represent all six canopy faces independently by tilt and azimuth and include mutual shading, temperature, soiling, electrical mismatch, inverter clipping, transformer losses, availability, and curtailment.

Reference concept values are documented in `ENERGY_MODEL.md`; they are not a substitute for a bankable PVsyst/SAM/PVGIS-based study.
